# last-light — «Последний огонёк»

Браузерная игра на HTML + CSS + Vanilla JavaScript + Canvas 2D.
Без npm, bundler и внешних зависимостей. Запуск: открыть `index.html` в браузере.

## Этап 1 — техническая основа

Реализовано:

- вертикальный игровой viewport 9:16 (логика 360×640, физический Canvas масштабируется под DPR);
- единая система мировых координат (одинакова на desktop и mobile);
- игровой цикл через `requestAnimationFrame` с delta time и защитой от больших dt;
- состояния игры: MENU, PLAYING, LEVEL_COMPLETE, LEVEL_FAILED, GAME_COMPLETE;
- уровни как данные (`js/levels.js`, 5 уровней), единый загрузчик `js/level.js`;
- игрок: постоянная скорость, радиус коллизии, раздельные `lookDirection` / `movementInput`;
- камера, не выходящая за границы мира (центрируется, если мир меньше viewport);
- стены-прямоугольники с коллизией circle-vs-rect и скольжением;
- управление мышью и touch через Pointer Events (одна input-система);
- дверь — цель уровня, переход к следующему уровню / GAME_COMPLETE;
- минимальный HUD (номер уровня, тестовая полоска заряда фонаря 100/100).

## Структура

```
index.html
style.css
js/
  config.js     — константы (логическое разрешение, игрок, ввод)
  collision.js  — коллизии (circle vs rect, скольжение)
  levels.js     — данные уровней
  level.js      — загрузчик уровня
  player.js     — игрок (взгляд и движение разделены)
  input.js      — Pointer Events: мышь + touch единообразно
  world.js      — камера (world→screen) + отрисовка
  ui.js         — HUD и экраны состояний (DOM)
  game.js       — состояния, цикл, переходы между уровнями
  main.js       — настройка Canvas под DPR, запуск
```

## Управление

- мышь: курсор задаёт направление взгляда; удержание ЛКМ — движение к курсору;
- touch: короткий тап — поворот; удержание/перетаскивание — движение;
- `R` — перезапустить уровень; `Enter`/`Space` — старт/дальше; `Esc` — в меню.
